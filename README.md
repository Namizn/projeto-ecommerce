# Análise de Dados - E-commerce (Kaggle Dataset)

## Objetivo
Realizar análise exploratória de dados de um dataset real de e-commerce, identificando padrões de vendas, faturamento e comportamento de clientes.

---

## Dataset
Fonte: Kaggle - E-commerce Data  
Contém informações de vendas internacionais, incluindo produtos, quantidades, preços e países.

---

## Tecnologias Utilizadas
- Python  
- Pandas  
- Matplotlib  

---

## Etapas do Projeto

### 1. Carregamento dos dados
Leitura do dataset e preparação inicial para análise.

### 2. Limpeza dos dados
- Remoção de valores nulos
- Filtragem de dados inconsistentes

### 3. Criação de métricas
- Cálculo de receita total (Quantity × UnitPrice)
- Conversão de datas

### 4. Análise exploratória
- Países com maior faturamento
- Produtos mais vendidos
- Evolução de vendas ao longo do tempo

### 5. Visualização
Gráficos de barras e linhas para interpretação dos dados.

---

## Resultados

- Identificação dos países com maior volume de receita  
- Produtos mais vendidos no período analisado  
- Tendência de vendas ao longo do tempo  
- Cálculo do faturamento total do e-commerce
